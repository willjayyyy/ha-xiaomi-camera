# Xiaomi Camera Bridge

Streams Xiaomi cameras over the vendor's peer-to-peer protocol and republishes
them as standard RTSP for Home Assistant and any NVR.

Install the **Xiaomi Camera** integration alongside this add-on so the cameras
appear as entities. See the Documentation tab for setup instructions.

**Requires the add-on to run on the same local network as the cameras.**

Installation downloads roughly 180 MB, so allow a few minutes for it.

---

# 小米摄像头桥接

通过小米官方的点对点协议获取摄像头画面，转换成标准 RTSP 输出，
供 Home Assistant 与各类 NVR 使用。

请同时安装 **Xiaomi Camera** 集成，摄像头才会成为 Home Assistant 中的实体。
配置步骤见「文档」标签页。

**加载项必须与摄像头运行在同一局域网内。**

安装需下载约 180 MB，请耐心等待几分钟。
